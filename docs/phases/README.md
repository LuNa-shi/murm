# 阶段协作

大阶段是人类控制的工作单元。每个大阶段拥有一个独立worktree和一份经人类批准的阶段说明，可以包含多个实现提交和实验，但只能有一个主要假设和明确的决定负责人。

## 人类和AI的分工

| 决定或行动 | 负责人 |
|---|---|
| 主要假设及其意义 | 人类 |
| 范围、非目标、允许变量和停止条件 | 人类 |
| 架构理解和最终因果判断 | 人类，AI提供证据支持 |
| 批准范围内的实现 | AI |
| 恢复已批准契约的bug修复 | AI |
| 确定性测试、probe和登记运行 | AI |
| Overview和证据索引 | AI起草；人类审阅后决定 |
| 新架构方向或假设变化 | 人类决定；修改阶段说明或开始新阶段 |

如果发现改变阶段假设、验收条件、fixture、provider/model、资源预算或架构边界，AI必须停止并报告变更提案，不能静默扩大worktree。

## 阶段流程

1. 人类写出并批准阶段说明。
2. AI整理相关架构并记录实现基线。
3. AI只在阶段worktree内实现阶段说明允许的变化。
4. 每次运行都使用新的规范`EXP-YYYYMMDD-NN`，并在运行前登记。
5. AI生成Overview和有证据支持的分析判断草稿。
6. 人类审阅报告并决定：继续、修改阶段说明、关闭阶段，或开始新的假设。

一次实验可能发现bug。如果它是契约或实现缺陷，并且仍在阶段说明范围内，可以直接修复。如果修复会改变实验正在检验的内容，就停止运行、记录发现，并重新登记实验或等待阶段决定。
