## Results

No formal execution or model calls. The private staged launcher exits before
launch while the owner’s two preconditions remain incomplete.

**Actual-target checker preflight: not passed.** In a private operator-only
probe, the upstream Q20 solution body was inserted into the unchanged fixture
and checked with the exact Q20 artifact lock above. The final result was FAIL,
`treecheck:2214dc27-fbb3-4cb1-8968-1a1aa3722521`: a required discriminant lemma
is absent from the allowed dependency environment. Direct source diagnostics
also reject target/solution constant lookups and import of the removed solution
module. The reference body depends on four removed theorem modules; the whole
Q20 cut contains 166 proof modules (36,068 source lines). These observations
establish neither an impossible theorem nor a checker implementation defect.
They establish that the available reference body is not yet a valid positive
control for the cut benchmark. Earlier helper PASS results do not fill this gap.

**Agent visibility audit: bounded checks passed.** The actual 88 public context
files plus unchanged target were prepared in the exact worker image. All 89
files matched the public manifest after preparation. Decompressed public shards
contain 60,474 module metadata entries; every one of the 166 Q20 cut modules
has declaration headers without a top-level proof body. The reference solution
body is absent. No compiled proof artifacts or Git history enter this input.
Module names, declaration statements, import edges, and the benchmark-approved
safe definitions remain public. Safe definitions contain auxiliary proofs;
other graph declarations may contain proof-valued terms inside their types.
This is the existing benchmark information policy, not a claim of zero proof
text anywhere in the allowed context.

A zero-model probe installed the production `DockerBotNetwork` and
`DockerBotDisk` policies, with the configured 96 MiB / 8,192-inode quota, then
executed under Bot UID 10001 and the image’s Landlock wrapper. Host FLT/source
checkouts, private experiment/reference storage, Workspace Git history, Docker
socket and host credentials were unreadable; the root worker environment was
also unreadable. Two dedicated harmless HTTP endpoints substituted for the
allowed Bridge/model address-port pairs and returned 200. An unlisted host
endpoint, lifecycle port, worker loopback port, public IPv4 HTTPS endpoint and
IPv6 loopback endpoint were unreachable. The rule set was read back by the
production installer. The sandbox was deleted and provider 404 verified.

Separate actual Mathlib service queries rejected relative/absolute path escape
and the removed target module with `INVALID_CONTRACT`; an unscoped target-name
search returned zero results. These checks cover the deployed input and tested
access boundaries, not a general proof against every possible information
channel or model pretraining contamination.
