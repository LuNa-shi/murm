## Analysis

The accepted target contains a concrete cross-worker dependency chain. Worker 2 proved the rank bound `prune_aug_rank_le`. Worker 3's `matchBound` calls it and yields the pruning theorem `prunePairs`. Worker 4 proved the extremal contradiction `not_strictExpansion_of_pruning`. Worker 1 used its reduction `exists_strictExpansion` and applied worker 4's contradiction with worker 3's pruning theorem to close the original target. The final-tree Judge accepted this composition. The underlying reduction also uses the transitive-blowup result initially claimed by worker 2.

In this paper-supplied case the public main remained at the unproved root for twenty minutes while workers accumulated independently checked local work. Five PRs subsequently merged between 11:04:06 and 11:10:07 UTC. The resulting tree closed the target. The case documents an early integration lag followed by successful mathematical assembly. It does not establish a sustained plateau or a speed advantage over SwarmEnv. This single native run overlapped EXP-08, experienced impaired local checking and an operational intervention, and used different timing and checker wrappers from the historical four-Core paper comparison.
