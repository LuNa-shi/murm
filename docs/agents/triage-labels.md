# Triage label mapping

> Configuration for Matt Pocock's `/triage` skill

| Canonical state role | GitHub label | Meaning |
|---|---|---|
| `needs-triage` | `needs-triage` | Maintainer evaluation required |
| `needs-info` | `needs-info` | Waiting for more information |
| `ready-for-agent` | `ready-for-agent` | Specification/brief sufficiently clear for an implementer |
| `ready-for-human` | `ready-for-human` | Human decision or intervention required |
| `wontfix` | `wontfix` | Will not be actioned |

The triage skill also uses category roles `bug` and `enhancement`. A label does not independently authorize spending, changing acceptance criteria or beginning a new research study; those boundaries remain governed by AGENTS.md and the relevant human instruction.
